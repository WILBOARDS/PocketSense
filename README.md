# PocketSense

A phone-first spending app for students. It helps you log what you buy in two taps, pause before bigger purchases, and save for one goal. All data stays on your phone.

- `app/`: the app (React + TypeScript, installable as a PWA). See [app/README.md](app/README.md) for how to run it.
- `design/`: the Claude Design handoff it was built from (prototype, design system, chat transcript).

## Quick start

```bash
cd app
npm install
npm run dev
```
