# PocketSense

A phone-first spending app for students. It helps you log what you buy in two taps, pause before bigger purchases, and save for one goal. Data stays on your phone unless you sign in to sync it with your PC (optional).

- `app/`: the app (React + TypeScript, installable as a PWA). See [app/README.md](app/README.md) for how to run it.
- `supabase/`: database tables, rules and email functions for accounts and sync. See [docs/ACCOUNTS-SETUP.md](docs/ACCOUNTS-SETUP.md).
- `design/`: the Claude Design handoff it was built from (prototype, design system, chat transcript).

## Quick start

```bash
cd app
npm install
npm run dev
```
